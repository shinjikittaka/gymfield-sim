# 47都道府県 3LDK 家賃ランキング

47都道府県の3LDK平均家賃を、**順位・全国平均との差・ヒートマップ・日本地図(色分け)**として
自動生成するツール一式です。データCSVを差し替えて再実行すれば、そのまま確定版になります。

## ⚠️ 現在のデータについて（重要）

同梱の `data/prefecture_3ldk_rent.csv` の家賃は **実測値ではなく推計値** です。

- **推計方法**: 全国平均 12万円 × 各都道府県の生活コスト係数（「暮らしコストラボ」2026年モデル準拠）
- **検索で実値を確認できたもの**: 東京 15万円 / 大阪 13万円 / 神奈川 係数1.10 / 秋田 係数0.83 / 沖縄 係数0.88
- 残りの県は上記モデルに沿って推計した近似値です。**そのままランキングの根拠として使わないでください。**

この生成環境は外部サイトへの直接アクセス（ページ取得）が組織のネットワークポリシーで遮断されており、
e-Stat・SUUMO・CHINTAI 等から47県分の実測値を自動収集できないため、暫定的に推計値を入れています。

## ✅ 確定版（実測値）にする手順

`data/prefecture_3ldk_rent.csv` の `rent_yen` 列を実測値へ差し替えて再実行するだけです。

```bash
python3 build_ranking.py
```

### 推奨データ源

| 種別 | ソース | 内容 |
|--|--|--|
| 公的・最も正確 | 総務省「小売物価統計調査（動向編）」民営家賃・3LDK区分 | e-Stat からCSV/Excelで取得可。都道府県庁所在市の実測家賃。 |
| 民間・実勢相場 | CHINTAI / SUUMO / LIFULL HOME'S の都道府県別「3LDK家賃相場」 | 掲載物件ベースの現在の相場。 |

> 手元にCSV・Excel・数値の一覧があれば、それを `rent_yen` に入れるだけで確定版になります。

## 生成物（`output/`）

| ファイル | 内容 |
|--|--|
| `ranking.md` | 順位つきMarkdown表（順位・地方・都道府県・平均家賃・全国平均との差・比・偏差値） |
| `ranking.xlsx` | Excel。家賃列にカラースケール、別シートに注記・出典。 |
| `heatmap.png` | 家賃の高い順の横棒ヒートマップ（全国平均ライン付き） |
| `map.png` | 日本地図の都道府県別コロプレス（色が濃いほど高い） |

## セットアップ & 実行

```bash
pip install pandas matplotlib openpyxl japanmap
python3 build_ranking.py
```

（日本語ラベルには IPAGothic フォントを使用します。無い環境では
`build_ranking.py` 冒頭の `_JP_FONT_CANDIDATES` に手持ちの日本語フォントパスを追加してください。）

## データ定義 `data/prefecture_3ldk_rent.csv`

| 列 | 説明 |
|--|--|
| `pref_code` | JIS都道府県コード（1〜47）。地図の塗り分けに使用。 |
| `region` | 地方区分（北海道/東北/関東/中部/近畿/中国/四国/九州/沖縄） |
| `prefecture` | 都道府県名 |
| `rent_yen` | 3LDK平均家賃（円）← **ここを実測値に差し替える** |
| `cost_coef` | 推計に使った生活コスト係数（参考。実測値に差し替える際は無視してよい） |
| `source` | データ種別・出典メモ |
